Reads the parsed Parquet data and works on it in memory, as DataFrames, on the Spark standalone cluster (one worker, 2 cores, 1 GB in the lite profile).

parsed Parquet → filter / group / count (in memory) → analytics Parquet
{% endcall %} {% call card("Hadoop MapReduce", "The classic engine, run on YARN through Hadoop Streaming.", "mapreduce/") %}

Reads the raw text and runs Python scripts: a mapper on every block, a combiner, a shuffle that sorts by key, then a reducer. Intermediate results go to disk between the steps.

mapper.py → combiner → shuffle + sort → reducer.py → /logs/mapreduce/<job>

Both engines use the same parser (loganalysis.parsing), so a line is either read the same way by both or rejected by both.
